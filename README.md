## 빌드

```bash
python3 scripts/prepare_data.py                 # 아홉 도시 정제 → data/site.json·도시별 *_parking.json
python3 scripts/prepare_data.py --city anyang   # 한 도시만 (suwon|seongnam|yongin|hwaseong|anyang|pyeongtaek|bucheon|goyang|namyangju|all, 기본 all)
python3 scripts/build_site.py --base https://parking.9welfare.com   # dist/ 175페이지 + 404.html + sitemap.xml, robots.txt
python3 -m http.server 8000 --directory dist   # 확인용 (종료: Ctrl+C)
```

`data/site.json`이 사이트 생성기의 입력입니다(`cities[]` + `lots[]`, 각 주차장에 `city`·`list_mode`).
`suwon_parking.json`·`seongnam_parking.json`·`yongin_parking.json`·`hwaseong_parking.json`·`anyang_parking.json`·`pyeongtaek_parking.json`·`bucheon_parking.json`·`goyang_parking.json`·`namyangju_parking.json`은 도시 단독 결과로, 검토·디버깅용으로 함께 커밋합니다.
수원도시공사 스냅샷의 수집 시각은 `data/raw/*_fetched_at.txt`에 적어 두어(파일 mtime 대신 사용)
다시 clone 해도 `snapshot_at`이 바뀌지 않습니다.

`--base`를 생략하면 기본값 `https://parking.9welfare.com`이 쓰입니다. canonical·Open Graph·JSON-LD·sitemap URL이
모두 이 값 기준으로 생성되므로, 다른 도메인에 배포할 때는 `--base https://내도메인`만 바꿔 다시 빌드하면 됩니다.

`dist/`는 상대경로로 만들어져 **파일을 그대로 열어도**(file://) 스타일과 계산기가 동작합니다.
유일한 예외가 `dist/404.html`입니다. 이 페이지는 주소창의 경로가 그대로 유지된 채 표시되므로
(Cloudflare Pages가 없는 주소에 이 파일을 돌려줌) 상대경로를 쓸 수 없어 링크·에셋을 사이트
절대경로(`/assets/...`, `/parking/...`)로 생성하고 `noindex`로 둡니다. 빌드할 때마다 자동 생성됩니다.

## 지도 링크 (카카오맵 · 네이버지도)

카드의 두 버튼은 `scripts/build_site.py`의 `map_links()`가 만듭니다.

| 버튼 | 형식 | 이유 |
|---|---|---|
| 카카오맵 | `https://map.kakao.com/link/map/{이름},{위도},{경도}` | 지정 좌표에 이름표가 달린 핀을 찍습니다. 이름은 `map_label()`로 다듬어 주차장이라는 말이 없으면 `공영주차장`/`주차장`을 붙입니다(예: `원천호수` → `원천호수 공영주차장`). |
| 네이버지도 | `https://map.naver.com/?lat={위도}&lng={경도}&dlevel=12&title={이름}` | 좌표에 **이름표가 달린 핀과 주소 카드**를 띄웁니다. `dlevel=12`는 지도 줌 16입니다. 이전 형식(`/p?c={경도},{위도},16,0,0,0,dh`)은 모바일에서 핀이 없었습니다 — 아래 설명 참고. |
| 노상 구간 표 | `https://map.kakao.com/link/search/{주소}` | 구간 이름(`중상32-75`)은 지도에서 검색되지 않아 도로명·지번 주소로 찾습니다. |

좌표가 없는 주차장은 두 버튼 모두 이름+시 이름 검색 링크로 대체합니다
(네이버는 `https://map.naver.com/?query={이름 시}&menu=location`).

### 네이버지도: 핀·이름이 뜨는 형식 (T-04b, 2026-11-17 확인)

`/p?c=…` 형식은 모바일 UA에서 앱 링크 페이지로 넘어갑니다.
리다이렉트를 따라가면 이렇게 끝납니다.

```
/p?c=127.0474431295,37.3029355951,16,0,0,0,dh
 → map.naver.com/?lng=…&lat=…&dlevel=12&mapMode=0&appTargetPage=map&appSchemeName=nmap&app=Y
 → m.map.naver.com/appLink.naver?…&appTargetPage=map&appSchemeName=nmap&app=Y   (지도 앱 호출 페이지)
```

`appTargetPage=map`이라 지도 앱이 **중심만 맞춘 화면**으로 열리고 핀·이름이 없습니다(신고된 증상).
`lat/lng/dlevel/title` 형식은 리다이렉트가 다릅니다.

| 환경 | 최종 주소 | 화면 |
|---|---|---|
| Android · iOS | `m.map.naver.com/map?lat=…&lng=…&dlevel=12&title=…` | 모바일 웹 지도 — 좌표에 핀, 하단 카드에 `title`과 역지오코딩 주소 (2026-11-17 확인) |
| PC | `map.naver.com/p/?title=…&lng=…&lat=…&zoom=16&type=0` | 지도 위 커스텀 핀 + 이름·주소 카드(저장·출발·도착) (2026-11-17 확인) |

`appTargetPage`가 붙지 않으므로 앱이 저절로 열리지 않고, 모바일 웹 지도가 핀을 보여 줍니다.
앱으로 보고 싶으면 그 화면의 `앱 열기` 버튼을 누르면 됩니다(핀이 찍힌 상태가 그대로 넘어감).
좌표가 없는 2곳(용인 기흥역환승·풍덕천2공영)은 `?query=…&menu=location` 검색 링크를 쓰는데,
`/p/search/…`는 모바일에서 `appTargetPage=search` 앱 호출로 넘어가서 피했습니다.
`qa_check.py`가 카드마다 `lat`·`lng`·`dlevel=12`·`title`(주차장 표기 포함)을 검사하고,
구형 `/p?c=`·`/p/search/` 링크와 `appTargetPage` 파라미터가 남아 있으면 실패로 잡습니다.

공공데이터 좌표가 실제 주차장이 아닌 곳을 가리키는 경우(호수 물가, 같은 단지의 다른 주차장 자리)는
`MAP_COORD_FIX`에 카카오맵·구글맵 장소로 확인한 좌표를 두고 **지도 링크에만** 적용합니다
(`data/site.json`은 원자료 그대로 두어 계산·동 추정 로직에 영향이 없습니다).
2026-11-16 기준 6곳: 수원 장안구 만석공원 제1~4(다섯 곳이 공원 좌표를 공유해 같은 지점에 찍혔음),
영통구 원천호수·신대호수(좌표가 호수 물가). `qa_check.py`가 링크 형식·라벨·보정 좌표를 검사합니다.

## 전국 확장: URL 슬러그는 자동 생성

URL은 `/{시·도}/{시·군}/{구}/{동}/` 구조이고, 구·동 이름의 영문 슬러그는 `scripts/build_site.py`가 만듭니다.

- **기존 주소는 고정**: 이미 공개된 수원시 29개 동·4개 구 슬러그는 `DONG_SLUG` / `GU_SLUG` /
  `data.suwon_parking.json`의 `districts[].slug` 매핑이 항상 우선하므로 한 글자도 바뀌지 않습니다.
  (예: `고색동 → goseak-dong`, `인계동 → ingye-dong`, `영통구 → suwon-yeongtong`)
- **새 지역은 자동**: 매핑에 없는 이름은 국어의 로마자 표기법(문화체육관광부 고시)에 따라 자동 생성합니다.
  행정 접미사는 하이픈으로 분리하고(`-dong`, `-eup`, `-myeon`, `-ri`, `-ga`, `-ro`, `-daero`, `-gil`, `-gu`, `-si`, `-gun`, `-do`),
  종성 대표음(ㄱ·ㄷ·ㅂ → k·t·p)과 ㄹ의 비음화·유음화(백로 → baengno, 신라 → silla)를 반영합니다.
  - `정자동 → jeongja-dong`, `판교동 → pangyo-dong`, `우만2동 → uman2-dong`, `경수대로 → gyeongsu-daero`
  - `분당구 → bundang-gu`, `성남시 → seongnam-si`, 시 슬러그는 접미사를 떼어 `seongnam`
  - 구 슬러그는 `시 슬러그 + 로마자` 형태로 `분당구 → seongnam-bundang`(수원시의 `suwon-yeongtong`과 같은 규칙)
- **충돌 방지**: 같은 구에서 로마자가 겹치면 이름 정렬 순서로 `-2`, `-3`을 붙여 결정적으로 분리합니다.
  (`dong_slug_map()` — 구 허브 표와 동 상세 페이지가 같은 결과를 쓰도록 한 곳에서 계산)
- 새 데이터를 넣을 때는 `data/*.json`에 `meta.region`·`districts[]`·`lots[].gu/dong`만 채우면 되고,
  `build_site.py`의 수동 딕셔너리를 고칠 필요가 없습니다. 표준데이터의 시·군 필터를 바꿔 `prepare_data.py`를
  재사용하면 다른 지자체도 같은 구조로 생성됩니다.

### 확장 안전 규칙 (T-03, 성남시부터 적용)

검색 품질을 지키기 위해 한 번에 **1~2개 시·군 단위**로만 확장하고, 아래를 지킵니다.

1. **빈 페이지·껍데기 페이지 금지**: 이름·주소·구획수가 없는 행은 페이지를 만들지 않고,
   동별 페이지는 `dong_page_min_lots`(성남·용인·화성 3곳, 수원시 1곳 — 기존 색인 URL 보존) 이상인 동만 생성합니다.
   기준 미달 동의 주차장은 구 페이지 목록·표에만 싣습니다. 주소에 동이 없고 좌표로도 확인되지 않는 주차장(용인 부설 등)은
   `동 미상` 묶음으로 구 페이지 표에만 두고 절대 페이지를 만들지 않습니다(`UNKNOWN_DONG`).
2. **형식이 다른 자료는 별도 페이지**: 성남시 노상 66구간은 이름이 `중상32-75` 같은 구간 번호라
   카드로 그리면 반복·빈약한 페이지가 되므로 `list_mode: "street"`로 분리해 전용 표 페이지 하나로 정리했습니다.
   용인시 노상 54구간도 같은 기준으로 분리했고, 무료·유료가 섞여 있어 `street_is_all_mixed()`로 문구·표 구성을 나눕니다.
3. **시·군 단위 묶음 커밋**: 도시 하나(정제·빌드·dist·문서)를 한 커밋으로 올려 되돌리기 쉽게 합니다.
4. **도시별 감면 규칙**: `cities[].discounts`에 조례 기준 감면(감면율 + 면제 시간)을 두면 계산기 버튼이
   그 도시 기준으로 생성됩니다. 성남시는 `장애인 1시간 면제 후 50%`, `국가유공자 12시간 면제 후 50%`를 반영했고,
   수원시는 조례(2025-01-01 시행) 기준 `경차·저공해·다자녀·임산부 50%`, `경증장애인·저공해1종 2시간 면제 후 50%`,
   `중증장애인·국가유공자 24시간 면제 후 50%`, `모범·유공납세자 100%`의 5단계로 80% 가정값 버튼을 대체했습니다(`T-02` B안).
   화성시는 조례 별표4 기준 5단계(`경차·저공해·다자녀 50%`, `경증장애인 2시간 면제 후 50%`,
   `국가유공자·중증장애인 100%`, `모범·유공납세자 100%`)로 버튼을 만듭니다.
- 안양시는 **급지별 누진 요금표**를 쓰므로 계산기가 한 가지 추가 요율만으로는 맞지 않습니다.
  `cities[].fee_table`(급지·기본요금·시간대별 요율)이 있으면 시 허브에 요금표를 그리고,
  카드의 `fee.steps`(시간대별 계단)·`fee.free_min`(최초 15분 무료)·`fee.cap_fee`(일일 최대요금)를
  `price_for()`(Python)·`priceFor()`(app.js)가 같은 규칙으로 계산합니다. 이 세 키가 없는 도시는 기존 계산 그대로입니다.
- **자치구가 없는 시**(평택시): `districts`에 시 이름 하나만 두고 그 슬러그를 시 슬러그와 같게 두면,
  `build_site.py`의 `is_city_wide()`가 시 페이지를 계산기·목록 페이지로 만들고(별도 구 페이지·중복 URL 없음)
  읍·면·동 페이지만 아래에 붙입니다. 노상 표의 지역 열은 ‘구’ 대신 ‘동·읍·면’이 됩니다.
- **급지별 고정 요율**(평택시): `cities[].fee_table.style = "grade_flat"`이면 시 페이지에
  ‘급지·기본시간·10분당 요율·1일 최대’ 표를 그리고, 카드의 `fee.base_min/base_fee/unit_fee/free_min/cap_fee`로
  같은 계산기 규칙을 씁니다. 기본요금이 0원이고 최초 N분이 무료인 요금(1급지 90분)은 `free_min`으로 표현합니다.
- `qa_check.py`가 기존 슬러그 불변·fallback 결과·충돌 해소·canonical 도메인을 함께 검사합니다.
